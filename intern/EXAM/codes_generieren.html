🔑 EXAM · Codes generieren

Anonyme Schüler-Codes für EXAM-Seiten – zum Ausdrucken und Ausschneiden.

1 · Codes erzeugen

Jeder Code besteht aus vier Zeichen und einem Prüfzeichen. Die EXAM-Seite erkennt am Prüfzeichen, ob ein Code gültig ist – auch Tippfehler und vertauschte Zeichen fallen auf. Es gibt keine Liste: Jedes Mal können neue Codes erzeugt werden.

Beim Drucken entstehen zwei Teile: Ihre Liste (Code + Name von Hand eintragen) und die Zettel zum Ausschneiden für die Klasse. Namen werden nirgends digital gespeichert.

2 · Code prüfen

Prüft, ob ein Code dem Muster entspricht – z. B. wenn ein Kind meldet, dass sein Code nicht angenommen wird.

3 · Link und QR-Code für einen Test

Für jeden Test einen eigenen Lehrer-Code wählen. Damit wird eine gesperrte EXAM-Seite wieder entsperrt. Der Link enthält nur einen Hash, nicht den Code selbst. Groß-/Kleinschreibung und Leerzeichen spielen keine Rolle.

🔒 Datenschutz

Diese Seiten sind bewusst datensparsam. Es gibt keinen Login und kein Nutzerkonto, und es werden keine personenbezogenen Daten auf einem Server gespeichert.

Was auf dem Gerät bleibt

Während du eine Aufgabe bearbeitest, speichert die Seite deinen Zwischenstand nur lokal im Zwischenspeicher deines eigenen Browser-Tabs (technisch: sessionStorage), damit beim Neuladen nichts verloren geht. Dieser Stand verlässt dein Gerät nicht und wird beim Schließen des Tabs automatisch gelöscht. Es werden keine Cookies gesetzt.

Hosting (GitHub Pages)

Die Seiten werden über GitHub Pages (GitHub, Inc.) bereitgestellt. Beim Aufruf überträgt dein Browser technisch notwendige Daten an GitHub – darunter deine IP-Adresse –, die serverseitig in Protokolldateien verarbeitet werden können. Darauf habe ich keinen Einfluss. Näheres regelt die Datenschutzerklärung von GitHub.

Externe Inhalte (MathJax)

Zur Darstellung mathematischer Formeln wird die Bibliothek MathJax beim Laden von einem Content-Delivery-Network (jsDelivr, CDN) geladen. Dabei wird technisch bedingt deine IP-Adresse an den CDN-Betreiber übermittelt. Weitere externe Dienste (etwa Web-Schriftarten) werden nicht nachgeladen.

Kurz gesagt: Die Seite selbst sammelt nichts über dich. Lediglich GitHub Pages (Hosting) und das MathJax-CDN sehen beim Aufruf deine IP-Adresse – das lässt sich beim Betrieb einer öffentlichen Website nicht vermeiden.

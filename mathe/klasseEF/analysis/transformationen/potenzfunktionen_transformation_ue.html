Übung: Transformationen von Potenzfunktionen

Wenden Sie an, was Sie über Potenzfunktionen mit positiven und negativen Exponenten und die Zahlen a, c und d gelernt haben – in drei Niveaustufen, mit einer kombinierten Aufgabe und einer Wiederholung zur Transformation von Funktionen 3. Grades.

1. Grundfunktionen: Potenzfunktionen mit Exponent n

Potenzfunktionen \( f(x) = x^n \) mit positiven und negativen Exponenten.

ohne HilfsmittelEigenschaften begründen

Betrachten Sie die Potenzfunktion \( f(x) = x^{-4} \). Bestimmen Sie die Stelle, an der f nicht definiert ist, und den Wert, dem sich f(x) für \(x\to\infty\) annähert.

nicht definiert für x = Annäherung an:
Tipp 1: Schreiben Sie \(x^{-4}\) als Bruch mit dem Zähler 1.
Tipp 2: Definitionslücke: Für welches x wird der Nenner null? Verhalten für \(x\to\infty\): Was passiert mit einem Bruch, dessen Nenner immer größer wird?
Lösungsweg: \(x^{-4}=\frac{1}{x^4}\). Der Nenner ist für x = 0 null, also ist f bei x = 0 nicht definiert. Für \(x\to\infty\) wird \(x^4\) beliebig groß, der Bruch beliebig klein: f(x) nähert sich 0 an (die x-Achse ist Asymptote).

2. Faktor a

\( g(x) = a\cdot x^n \). Bezugspunkte: \(P(1|1)\) für jedes n und \(Q(-1|q)\) mit q = 1 für gerade n bzw. q = −1 für ungerade n.

Aufgabe

ohne Hilfsmittelrechnerisch

Der Graph von \( f(x) = x^4 \) wird mit dem Faktor 3 in y-Richtung gestreckt: \( g(x) = 3\cdot x^4 \). Auf welchen Punkt P' wird \(P(1|1)\) abgebildet?

Aufgabe

ohne Hilfsmittelrechnerisch

Gegeben ist \( g(x) = -2\cdot x^3 \). Weil n = 3 ungerade ist, liegt \(Q(-1|-1)\) auf dem Graphen von \(f(x)=x^3\). Bestimmen Sie die y-Koordinate des Bildpunkts Q'.

Q'(−1 | )
Tipp 1: Der Faktor a wirkt nur auf die y-Koordinate.
Tipp 2: Multiplizieren Sie die y-Koordinate von Q mit a – achten Sie auf beide Vorzeichen.
Lösungsweg: \(Q'(-1|-2\cdot(-1))=Q'(-1|2)\).

Aufgabe

ohne Hilfsmittelrechnerisch

Der Graph von \( g(x) = a\cdot x^3 \) geht durch den Punkt \(Q'(-1|-6)\). Bestimmen Sie den Faktor a.

a =
Tipp 1: Setzen Sie die Koordinaten von Q' in die Funktionsgleichung ein.
Tipp 2: Berechnen Sie zuerst \((-1)^3\) und lösen Sie dann die Gleichung nach a auf.
Lösungsweg: \(-6=a\cdot(-1)^3=-a\), also \(a=6\).

3. Parameter c

\( h(x) = (x-c)^n \). Bezugspunkte: \(P(1|1)\) für jedes n und \(Q(-1|q)\) mit q = 1 für gerade n bzw. q = −1 für ungerade n.

Aufgabe

ohne Hilfsmittelrechnerisch

Der Graph von \( f(x) = x^2 \) wird um 5 Einheiten nach rechts verschoben: \( h(x) = (x-5)^2 \). Auf welchen Punkt wird \(P(1|1)\) abgebildet?

Aufgabe

ohne Hilfsmittelrechnerisch

Gegeben ist \( h(x) = (x-7)^4 \). Weil n = 4 gerade ist, liegt \(Q(-1|1)\) auf dem Graphen von \(f(x)=x^4\). Bestimmen Sie die x-Koordinate des Bildpunkts Q'.

Tipp 1: Der Term \((x-7)\) verschiebt den Graphen waagerecht – um wie viel und in welche Richtung?
Tipp 2: Addieren Sie c zur x-Koordinate von Q.
Lösungsweg: \(-1+7=6\), also \(Q'(6|1)\).

Aufgabe

ohne Hilfsmittelrechnerisch

Der Graph von \( h(x) = (x-c)^5 \) geht durch \(P'(10|1)\), den Bildpunkt von \(P(1|1)\). Bestimmen Sie c.

Tipp 2: Die x-Koordinate von P' ist \(1+c\). Stellen Sie damit eine Gleichung auf und lösen Sie sie.

4. Parameter d

\( j(x) = x^n+d \). Bezugspunkte: \(P(1|1)\) für jedes n und \(Q(-1|q)\) mit q = 1 für gerade n bzw. q = −1 für ungerade n.

ohne Hilfsmittelrechnerisch

Der Graph von \( f(x) = x^3 \) wird um 4 Einheiten nach unten verschoben: \( j(x) = x^3-4 \). Auf welchen Punkt wird \(Q(-1|-1)\) abgebildet?

ohne Hilfsmittelrechnerisch

Gegeben ist \( j(x) = x^4+6 \). Der Punkt \(P(1|1)\) liegt auf dem Graphen von \(f(x)=x^4\). Bestimmen Sie die y-Koordinate des Bildpunkts P'.

Tipp 2: Addieren Sie d zur y-Koordinate von P.
Lösungsweg: \(1+6=7\), also \(P'(1|7)\).

ohne Hilfsmittelrechnerisch

5. Kombination: a, c und d

\( g(x) = a\cdot(x-c)^n+d \). Bezugspunkte: \(P(1|1)\) für jedes n und \(Q(-1|q)\) mit q = 1 für gerade n bzw. q = −1 für ungerade n.

ohne HilfsmittelEigenschaften begründen

Aufgabe

ohne Hilfsmittelrechnerisch

Gegeben ist \( g(x) = 3\cdot(x-2)^4+1 \). Der Punkt \(P(1|1)\) liegt auf dem Graphen von \(f(x)=x^4\). Bestimmen Sie den Bildpunkt P'.

P'( | )
Tipp 1: Gehen Sie Koordinate für Koordinate vor: c wirkt auf x, a und d wirken auf y.
Tipp 2: Für die y-Koordinate erst mit a multiplizieren, dann d addieren.
Lösungsweg: x-Koordinate: \(1+2=3\). y-Koordinate: \(3\cdot 1+1=4\). Also \(P'(3|4)\).

Tipp 1: Bestimmen Sie c aus den x-Koordinaten von P und P' (oder Q und Q').
Tipp 2: Für die y-Koordinaten gilt \(a\cdot 1+d\) bzw. \(a\cdot(-1)+d\). Stellen Sie damit zwei Gleichungen auf und lösen Sie das Gleichungssystem.

6. Wiederholung: Transformation von Funktionen 3. Grades

Frischen Sie Ihr Wissen zu den Zahlen a, c und d bei \( f(x) = x^3-3x \) auf. Der Graph hat den Hochpunkt \(HP(-1|2)\) und den Tiefpunkt \(TP(1|-2)\).

Aufgabe

ohne Hilfsmittelrechnerisch

Bei welcher der folgenden Transformationen von \( f(x) = x^3-3x \) ändert sich die x-Koordinate des Hochpunkts?

Aufgabe

ohne Hilfsmittelrechnerisch

Gegeben ist \( g(x) = f(x-2)+4 \) mit \( f(x) = x^3-3x \) und dem Hochpunkt \(HP(-1|2)\) von f. Bestimmen Sie den Hochpunkt HP' von g.

HP'( | )
Tipp 1: Ordnen Sie zu: Welche Zahl verschiebt waagerecht, welche senkrecht?
Tipp 2: Addieren Sie c zur x-Koordinate und d zur y-Koordinate des Hochpunkts.
Lösungsweg: x-Koordinate: \(-1+2=1\). y-Koordinate: \(2+4=6\). Also \(HP'(1|6)\).

Der Tiefpunkt von \( g(x) = f(x-c)+d \) mit \( f(x) = x^3-3x \) liegt bei \(TP'(4|1)\). Der Tiefpunkt von f ist \(TP(1|-2)\). Bestimmen Sie c und d.

Tipp 1: Vergleichen Sie TP und TP' Koordinate für Koordinate.
Tipp 2: Stellen Sie für jede Koordinate eine Gleichung auf: x-Koordinate von TP plus c, y-Koordinate von TP plus d.

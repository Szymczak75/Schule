Extremwertprobleme mit Nebenbedingungen – Übung I

Aufgabe – Niveau 1

ohne Hilfsmittelrechnerisch

Gegeben ist eine lineare Funktion \(f(x)=-0{,}5x+3\) in dem Intervall \([0;\,5]\). Unter dem Graphen der Funktion wird im ersten Quadranten ein Rechteck aufgespannt. Ein Eckpunkt liegt im Ursprung, der gegenüberliegende Punkt \(P(x\,|\,f(x))\) auf dem Graphen von \(f\) und die anderen beiden Eckpunkte liegen jeweils auf den Koordinatenachsen.

Bestimmen Sie die Koordinaten des Punktes \(P\) so, dass der Flächeninhalt \(A\) des Rechtecks maximal wird.

  1. Erstellen Sie eine Skizze des beschriebenen Problems.
  2. Führen Sie die vier Schritte zur Lösung eines Extremwertproblems mit Nebenbedingung durch.
  3. Formulieren Sie einen Antwortsatz.

Musterlösung

a) Skizze: siehe Hilfekarte 2.

b) Die vier Schritte

  1. Hauptbedingung: \(A = x\cdot y\)
  2. Nebenbedingung: Breite \(x\), Höhe \(y = f(x) = -0{,}5x+3\).
    Definitionsbereich: \(D = [0;\,5]\). Dort gilt \(f(x) > 0\), das Rechteck liegt also immer im ersten Quadranten.
  3. Zielfunktion: \(A(x) = x\cdot(-0{,}5x+3) = -0{,}5x^2+3x\)
  4. Extremum bestimmen:
    \(A'(x) = -x+3\) und \(A''(x) = -1\)
    \(A'(x) = 0 \;\Leftrightarrow\; x = 3\)
    \(A''(3) = -1 < 0\), also liegt bei \(x = 3\) ein lokales Maximum vor: \(A(3) = -4{,}5+9 = 4{,}5\).
    Randwerte: \(A(0) = 0\) und \(A(5) = -12{,}5+15 = 2{,}5\). Beide sind kleiner als \(4{,}5\), also ist \(x = 3\) das globale Maximum.
    \(f(3) = -1{,}5+3 = 1{,}5\)

c) Antwortsatz: Für \(P(3\,|\,1{,}5)\) wird der Flächeninhalt des Rechtecks maximal. Er beträgt \(A_{\max} = 4{,}5\) FE.

Musterlösung

a) Skizze: siehe Hilfekarte 2.

b) Die vier Schritte

  1. Hauptbedingung: \(A = \text{Breite}\cdot\text{Höhe}\)
  2. Nebenbedingung: Breite \(x\), Höhe \(|f(x)|\) mit \(f(x) = -(x-2)^2+4 = -x^2+4x\).
    Definitionsbereich: \(D = [0;\,5]\)
    Nullstellen: \(-x^2+4x = x\cdot(-x+4) = 0 \;\Rightarrow\; x = 0\) oder \(x = 4\).
    Für \(4 < x \leq 5\) ist \(f(x) < 0\). Das Rechteck klappt dort unter die \(x\)-Achse. Der Term \(x\cdot f(x)\) wird negativ, der Flächeninhalt aber bleibt positiv. Deshalb gilt \(A(x) = x\cdot|f(x)|\).
  3. Zielfunktion (abschnittsweise):
    \(A(x) = -x^3+4x^2\) für \(0 \leq x \leq 4\)
    \(A(x) = x^3-4x^2\) für \(4 < x \leq 5\)
  4. Extremum bestimmen:
    Abschnitt \([0;\,4]\):
    \(A'(x) = -3x^2+8x = x\cdot(-3x+8) = 0 \;\Rightarrow\; x = 0\) oder \(x = \dfrac{8}{3}\)
    \(A''(x) = -6x+8\) und \(A''\!\left(\dfrac{8}{3}\right) = -8 < 0\), also liegt dort ein lokales Maximum vor.
    \(A\!\left(\dfrac{8}{3}\right) = -\dfrac{512}{27}+\dfrac{768}{27} = \dfrac{256}{27} \approx 9{,}48\)
    Abschnitt \((4;\,5]\):
    \(A'(x) = 3x^2-8x = x\cdot(3x-8)\). Die Nullstellen \(0\) und \(\dfrac{8}{3}\) liegen nicht im Abschnitt.
    Für \(x > 4\) ist \(A'(x) > 0\), also wächst \(A\) dort streng monoton. Das Maximum liegt am rechten Rand.
    Randwerte:
    \(A(0) = 0\) und \(A(4) = 0\)
    \(A(5) = 5\cdot|f(5)| = 5\cdot|{-5}| = 25\)
    Wegen \(25 > 9{,}48\) liegt das globale Maximum am Rand bei \(x = 5\).

c) Antwortsatz: Für \(P(5\,|\,{-5})\) wird der Flächeninhalt des Rechtecks maximal. Er beträgt \(A_{\max} = 25\) FE. Das Rechteck liegt dann unterhalb der \(x\)-Achse.
Das lokale Maximum bei \(x = \dfrac{8}{3}\) mit \(A \approx 9{,}48\) FE ist kleiner.

Musterlösung

a) Skizze: siehe Hilfekarte 2.

b) Die vier Schritte

  1. Hauptbedingung: \(A = \text{Breite}\cdot\text{Höhe}\)
  2. Nebenbedingung: Breite \(x\), Höhe \(|f(x)|\) mit \(f(x) = x^3-7x^2+11x\).
    Definitionsbereich: \(D = [0;\,4{,}75]\)
    Nullstellen: \(x\cdot(x^2-7x+11) = 0 \;\Rightarrow\; x = 0\) oder \(x = \dfrac{7\pm\sqrt{5}}{2}\), also \(x_1 \approx 2{,}38\) und \(x_2 \approx 4{,}62\).
    Zwischen \(x_1\) und \(x_2\) ist \(f(x) < 0\). Das Rechteck klappt dort unter die \(x\)-Achse. Der Flächeninhalt bleibt positiv, deshalb gilt \(A(x) = x\cdot|f(x)|\).
  3. Zielfunktion (abschnittsweise):
    \(A(x) = x^4-7x^3+11x^2\) für \(x \in [0;\,x_1] \cup [x_2;\,4{,}75]\)
    \(A(x) = -(x^4-7x^3+11x^2)\) für \(x \in (x_1;\,x_2)\)
  4. Extremum bestimmen:
    Für \(g(x) = x^4-7x^3+11x^2\) gilt \(g'(x) = 4x^3-21x^2+22x\) und \(g''(x) = 12x^2-42x+22\).
    \(g'(x) = x\cdot(4x^2-21x+22) = 0 \;\Rightarrow\; x = 0\) oder \(x^2-5{,}25x+5{,}5 = 0\)
    pq-Formel: \(x = 2{,}625 \pm \sqrt{2{,}625^2-5{,}5} = 2{,}625 \pm \sqrt{1{,}390625}\)
    \(x_3 \approx 1{,}45\) und \(x_4 \approx 3{,}80\)
    Abschnitt \([0;\,x_1]\): \(A = g\), \(A''(1{,}45) = g''(1{,}45) \approx -13{,}6 < 0\), also liegt dort ein lokales Maximum vor.
    \(A(1{,}45) \approx 1{,}45\cdot 4{,}29 \approx 6{,}21\)
    Abschnitt \((x_1;\,x_2)\): \(A = -g\), \(A''(3{,}80) = -g''(3{,}80) \approx -35{,}9 < 0\), also liegt dort ein lokales Maximum vor.
    \(A(3{,}80) = 3{,}80\cdot|f(3{,}80)| \approx 3{,}80\cdot 4{,}40 \approx 16{,}75\)
    Abschnitt \([x_2;\,4{,}75]\): \(A = g\). Hier liegt keine Nullstelle von \(g'\), und \(g'(4{,}7) > 0\). Also wächst \(A\) dort, und das Maximum liegt am Rand.
    Randwerte:
    \(A(0) = 0\), \(A(x_1) = 0\) und \(A(x_2) = 0\)
    \(A(4{,}75) = 4{,}75\cdot 1{,}484375 \approx 7{,}05\)
    Vergleich: \(16{,}75 > 7{,}05 > 6{,}21\). Das globale Maximum liegt also bei \(x_4 \approx 3{,}80\).

c) Antwortsatz: Für \(P(3{,}80\,|\,{-4{,}40})\) wird der Flächeninhalt des Rechtecks maximal. Er beträgt \(A_{\max} \approx 16{,}75\) FE. Das Rechteck liegt dann unterhalb der \(x\)-Achse.

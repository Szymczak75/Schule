2 · Was du ins andere Projekt schreibst

Kopiere diesen Absatz in die Projektanweisungen des Zielprojekts:

Interaktives Geodreieck. Wenn eine Aufgabe das Untersuchen von Geradenlagen, Winkeln, Parallelität oder Orthogonalität betrifft (Klasse 5–7, Geometrie) und es didaktisch sinnvoll ist, das Geodreieck anzulegen, binde das wiederverwendbare Geodreieck-Modul ein (Referenzdatei „geodreieck_baustein.html“ im Projektwissen). Übernimm Code und Styles von dort, statt sie neu zu erfinden. Pflichtregeln: Gedreht wird am orangen Dreh-Griff am Geodreieck (im Kreis ziehen) oder per Presets; verschoben wird durch Ziehen auf der Fläche. Beides per Pointer-Events mit setPointerCapture sauber getrennt (Griff = drehen, Fläche = verschieben) – kein Springen am iPad. Zustand nur im JS-Speicher, kein localStorage. Aufruf über mountGeodreieck(container, geraden, optionen).
Wichtig: Lege diese Datei wirklich ins Projektwissen (nicht nur in einen Chat). Nur dann findet Claude sie später per Projektsuche und kann den Baustein übernehmen.

3 · Schnittstelle

mountGeodreieck(container, geraden, optionen)

container : DOM-Element ODER dessen id (String), in das alles gerendert wird.
geraden   : Array von Geraden-Objekten, jeweils Pixelkoordinaten im 0–400-Raster:
            { x1, y1, x2, y2, color }   // color optional, sonst Standardfarbe
optionen  : (optional) {
              start:   {x:200, y:200, rot:0},   // Startlage des Geodreiecks
              hint:    true,                     // Bedien-Hinweistext anzeigen
              presets: [0,45,90,135]             // Schnellwahl-Drehwinkel
            }

Rückgabe  : Steuerobjekt { setRot(grad), reset(), getState(), setGeraden(arr) }

Das Koordinatensystem der Zeichenfläche ist 0–400 (viewBox). Ursprung oben links,
y zeigt nach unten (SVG-Standard). Geraden also in diesem Raster angeben.

4 · Verwendungsbeispiel

<div id="meinGeo"></div>
<script>
  const steuer = mountGeodreieck('meinGeo', [
    { x1:50,  y1:140, x2:350, y2:140, color:'#d6336c' },
    { x1:50,  y1:260, x2:350, y2:260, color:'#1f9d55' }
  ], { start:{x:200,y:120,rot:0}, hint:true });

  // später z.B. programmatisch drehen oder Geraden wechseln:
  // steuer.setRot(90);
  // steuer.setGeraden([...]);
</script>
